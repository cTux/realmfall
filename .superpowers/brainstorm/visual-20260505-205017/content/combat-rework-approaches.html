Combat Rework Direction

Pick the implementation shape that feels right. I recommend B because it keeps the new combat behavior consistent across click-to-engage and dungeon chase encounters.

Approach A

App-Layer Intent

Keep most combat state unchanged. Intercept enemy-hex clicks in the world controller, remember the clicked enemy hex in app state, and resolve the post-victory step from the UI layer.

Pros

  • Smallest initial diff
  • Least churn in combat modules

Cons

  • Special-cases click flow
  • Dungeon chase logic has to duplicate the same idea
  • Post-combat movement intent lives outside gameplay state
Approach B (Recommended)

Encounter Metadata In Game State

Extend encounter creation with metadata about how the fight started: clicked enemy hex, staging hex, and whether victory should auto-step onto the target. Combat always auto-starts, and the renderer consumes the same encounter metadata for the visual lunge and floating text anchors.

Pros

  • One rule-set for clicks and dungeon chase
  • Post-combat auto-step becomes deterministic
  • Visual world overlays can derive from real combat intent

Cons

  • Touches encounter creation and combat completion paths
  • Needs a few more state and test updates
Approach C

Full Position Virtualization

Move the player into the enemy hex in gameplay state at encounter start, then emulate the pre-combat or post-combat position visually and logically from there.

Pros

  • Single occupied hex during combat

Cons

  • Breaks your no-move-cost rule for adjacent engagement
  • More regression risk in movement, loot, and dungeon pursuit
  • Harder to explain with deferred victory movement

Recommended Flow

Approach B Behavior Timeline
Adjacent Enemy Click

1. Click enemy hex.

2. No real move, no move cooldown.

3. Combat auto-starts immediately.

4. Player badge visually lunges toward the enemy hex.

5. On victory, player auto-steps onto that hex and starts movement cooldown.

Far Enemy Click / Dungeon Chase

1. Move toward the nearest adjacent staging hex.

2. Start combat immediately on arrival or on enemy chase contact.

3. Keep the original enemy hex as the post-victory destination.

4. On victory, auto-step into that target hex and start movement cooldown.

5. HP/MP rings and floating damage/heal text stay attached to world hex frames.
